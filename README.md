### What I learned

I learned how to include an image that was inside in a folder.

```html
	<img src="./images/image-qr-code.png" />
```

About CSS I learned a lot of things; how to use margin, and differences between margin and padding. Also, I've lernead that I have to start with mobile style.

```css
.container {
    max-width: 250px;
    margin: 80px auto 80px auto;
    background-color: hsl(0,0%, 100%);
    padding: 15px 15px 20px 15px;
    border-radius: 14px;
}
```
